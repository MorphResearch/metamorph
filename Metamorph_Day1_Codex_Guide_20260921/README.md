# Metamorph Day 1 指引包

这是给本地 Codex 的实施指引和原始设计资料，不包含已经完成的实验代码或运行结果。

1. 将 `docs/experience_value/` 放进你现有的 Metamorph 项目。遇到同名文件先比较，勿覆盖自己或同事的修改。
2. 在该项目的 Codex 会话中，明确要求先读取 `docs/experience_value/CODEX_DAY1.md`。
3. 默认执行仓库检查、局部实现、离线测试和 dry-run。真实模型微测试必须另有具体模型和预算授权。
4. 不要将指引替换成全局 AGENTS.md；它只适用于今天的实验任务。
5. 本任务书中的路径是建议本地位置，真实仓库由 Codex 检查后确认。ChatGPT 的 sandbox 路径不是你的 Mac 路径。

`reference/` 保留上一轮完整研究清单与配置草稿，未修改其内容。今天新增的实现默认值和测试要求在 CODEX_DAY1.md 中显式说明。
