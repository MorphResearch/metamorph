# Day-1 design decisions

| Date | Decision | Reason and evidence | Not frozen / confirmation needed |
|---|---|---|---|
| 2026-09-21 | `F = prompt_prescribed_v0` in the same single-agent loop | E0 needs to validate experience transport before adding a planner/reviewer/router. The prompt is stored and hashed. | This is a development default, not a program-enforced formal protocol. |
| 2026-09-21 | Use a synthetic metered SQLite `local_fixture` when no verified CL-Bench Database Exploration integration is present | It validates real query results, query failures, limits, snapshots, and receiver injection without claiming a benchmark result. | Public environment version, commit, IDs, and scorer remain unconfirmed. |
| 2026-09-21 | Disable arbitrary agent code execution | Repository inspection found workspace confinement but no verifiable OS/container sandbox appropriate for untrusted agent code. | `code_execution_isolation=BLOCKED`; do not replace it with host execution. |
| 2026-09-21 | Live requests default to blocked | No explicit model, price basis, currency cap, request limits, or authorization were supplied for this E0 request. | Researcher must explicitly confirm all live-smoke fields. |
| 2026-09-21 | Tool-only microtest may use `read_file`, `write_file`, and metered `query_sql` only | The new adapter reuses the existing agent loop with an E0-local tool allowlist; fake-transport tests cover tool pairing, fresh first messages, timeout/retry binding, and conservative accounting. | Code files remain inert static artifacts. This is a temporary microtest boundary, not a permanent restriction on the study's open artifact formats. |
| 2026-09-21 | Signed live smoke uses explicit DeepSeek thinking (`enabled`, `reasoning_effort=low`) | The thin existing OpenAI-compatible adapter sends the documented `extra_body.thinking` flag, binds SDK retries to zero and replays returned `reasoning_content` on tool continuation. Thinking requests omit `temperature` and the explicit `tool_choice` field. | Applies only to the three authorized local-fixture episodes; it does not freeze the formal protocol. |
| 2026-09-21 | Signed limits are 6 model requests and 6 total tool calls per episode, with USD 0.20 across exactly three episodes | A pessimistic peak cache-miss reservation of 5,120 input + 512 output tokens is USD 0.00878592/request; 18 reservations total USD 0.15814656, below USD 0.20. | Provider billing is not an invoice: missing usage keeps its reservation and halts later calls. |
| 2026-09-21 | Separate runner return, budget stop, evaluator execution, and task correctness in the result layer | Offline audit found `metrics.success` meant only `bool(answer)`. Two budget-capped probes returned unexecuted DSML text, so future result records expose separate fields and preserve historical values. | No claim is made about the absent raw provider objects or historical tool-call IDs. |
| 2026-09-21 | Explicitly describe optional immutable `/memory` cloning in all F/U source prompts | The completed source run had an optional `/memory` save instruction but did not explicitly state that a later new session could receive a clone. This wording makes the experience route visible without requiring an artifact. | This prompt correction was not applied retrospectively or rerun; receiver/task prompts remain otherwise unchanged. |
| 2026-09-21 | Add `list_dir` as the bounded common discovery tool | The live audit found repeated guesses for task and artifact filenames. `list_dir` exposes only direct logical names/types, shares the existing tool budget, and preserves path/symlink isolation. | This is an interface revision and must not be combined with the completed live-smoke result. |
| 2026-09-21 | Prepare, but do not run, a forced-save file positive control | PC-SOURCE tests the real file route separately from U1; PC-MEMORY and PC-EMPTY have identical probe instructions and independent snapshots. | Pending model, price, and spend signoff; excluded from primary analysis and F/U samples. |
